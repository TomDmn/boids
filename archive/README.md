## Français

Versions intermédiaires et expérimentations conservées à titre d'historique.
Les fichiers finaux et maintenus sont dans [`src/`](../src).

- **`boid_rebond.c`** — variante où les boids rebondissent sur les bords au lieu
  de traverser l'écran (pas d'effet de tore).
- **`boids_JR2.c`** — variante de l'équipe avec prédateur et bombes (avant la
  version finale à virgule fixe de `src/boids_predateur_bombe.c`).
- **`boids_sans_pred_bombe.c`** — la version à virgule fixe (hachage spatial,
  arithmétique `fx`) mais sans prédateur ni bombes.
- **`boids_test.c`** — fichier de test / expérimentations diverses.
- **`boids.py`**, **`boids_rebond.py`** — prototypes en Python, avant le passage
  définitif au C.
- **`projet_programmation_aziz_tom_jeanrene/`** — une itération antérieure du
  projet, réalisée avec d'autres coéquipiers.

## English

Intermediate versions and experiments kept for historical reference.
The final, maintained files are in [`src/`](../src).

- **`boid_rebond.c`** — variant where boids bounce off the edges instead of
  wrapping around the screen (no toroidal effect).
- **`boids_JR2.c`** — team variant with predator and bombs (before the final
  fixed-point version in `src/boids_predateur_bombe.c`).
- **`boids_sans_pred_bombe.c`** — the fixed-point version (spatial hashing,
  `fx` arithmetic) but without the predator or bombs.
- **`boids_test.c`** — test file / miscellaneous experiments.
- **`boids.py`**, **`boids_rebond.py`** — Python prototypes, before the final
  move to C.
- **`projet_programmation_aziz_tom_jeanrene/`** — an earlier iteration of the
  project, made with different teammates.
